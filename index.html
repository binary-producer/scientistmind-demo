项目简介

科研规划需要把宽泛目标转化为可检验的机制、对照实验和评价指标。仅提出“查阅文献”或“优化参数”，仍难以支持研究者比较竞争解释。

ScientistMind Agent 面向开放式科研问题，将科学家研究案例整理为可复用的思维模板，结合规则路由、本地检索和 Persona 配置，组织可检验的假设、实验、指标与风险。

系统以本地规则与模板为主，支持可选 CPU 向量检索及人工审核后的资料扩展，并预留了未来接入大语言模型的提示接口。系统的实际用途是辅助组织科研讨论，输出的科学假设仍需专业文献与实验支持。

Project Introduction

ScientistMind Agent structures scientist case studies into reusable thinking patterns. It combines rule-based routing, local retrieval and Persona configurations to organize testable hypotheses, experiments, metrics and risks. The current prototype uses local rules and templates, with a prepared prompt interface for future LLM integration.

路由与本地检索

路由器通过关键词与规则识别领域和研究性质，推荐模板及 Persona，当前覆盖材料、催化、生物工程、测量物理、理论物理与通用规划。规则易于追踪，但对措辞和跨领域输入较敏感，复杂任务仍需人工调整。

检索模块采用 BM25 风格评分，并结合标题、文档类型和查询扩展。可选 CPU 向量索引用语义相似性补充候选，索引缺失时回退到 BM25。当前混合结果以 BM25 排名优先，属于 BM25 优先的候选合并，尚不能声称向量检索改善了最终排名。

规划生成与资料扩展

Scientist Agent 按领域模板组织问题分解、机制假设、实验对照、主次指标、风险和时间线，Persona 随后增加追问与额外控制条件。当前生成主要依赖本地规则和配置。

Streamlit 界面展示路由依据、检索条目、研究方案及 Persona 对比，使用户能够回看方案形成过程。系统还支持搜索学术元数据，候选经人工接受后进入用户索引；元数据中的题名、摘要和链接不等于已核验的论文全文。

说明

该示例属于规划输出，展示的是可供讨论的假设与实验框架，而非实验结果。建议仍需细化变量、样本量、对照和统计方法；初始效率变化与寿命变化应分开分析，加速老化结果也不能直接替代实际使用寿命。本项目未开展器件制备与老化实验，输出中的试验周期属于模板建议。

评测有效性说明

评分偏差

四系统评分为不同方法预设 0、0.4、0.9 和 1.1 的加分，并在多个维度中使用。即使输出内容相同，方法名称也可能改变分数。因此表1的逐级升高混合了结构覆盖与评分先验，关键词命中也不保证事实与机制成立。

答案泄漏

历史回放直接读取评测集中的参考假设、实验与关键词，再对相同内容评分，其满分不构成独立发现能力证据。假设生成循环使用基础假设并追加编号，10 条输出不等于 10 个独立机制。

其他局限

知识库规模较小；人物案例不能替代专业研究证据；路由依赖手工规则；Persona 主要补充文字，其实际收益未经验证。

这些结果更适合检查工程链路，不能证明系统提升了真实科研能力或具备独立发现能力。

结论

ScientistMind Agent 的主要成果是将案例、方法选择、证据检索与规划输出组织为可维护的原型。结构化报告帮助使用者发现缺少的对照、读数和风险说明，界面与来源记录提供了审查入口。

项目已形成可解释的科研规划流程，内部数据能够复现，结论限定为原型实现及输出结构可检查；科研假设质量与实际效益尚未经独立验证。
